지금 화면의 선택지

등급은 op.gg처럼 실전 승률 통계가 아니라, 선택한 무기/핵심 아이템과 겹치는 태그·키워드 + 희귀도를 섞은 휴리스틱입니다. "무기 호환성 점검"은 등급 계산과 별도 단계로, 아이템이 의존하는 조건(일반공격/연격/탄환 등) 각각을 선택한 무기가 그대로 제공하는지(✓), 바꾸거나 없애버리는지(⚠ 충돌), 아니면 무기 텍스트에 아예 언급이 없는지(무관) 하나씩 대조해서 보여줍니다. 텍스트 키워드 매칭이라 완벽하지 않으니 ⚠가 붙은 조합은 꼭 직접 확인해주세요. 석판 후보의 등급은 희귀도만 반영하지만(선택 단계에선 아직 어디 놓일지 모르므로), 아래 배치 계산은 게임에서 읽은 석판 효과 범위를 그대로 씁니다.

배치 계산 (담은 아이템 + 현재 인벤토리)

후보 카드에서 "배치 목록에 담기"를 누르면 여기 추가됩니다. 게임 레벨 규칙을 그대로 재현한 엔진으로 레벨 합이 가장 큰 배치를 찾습니다.
